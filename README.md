# MarkMind

**把书签整理成真正好用的收藏库。**

MarkMind 是适用于 Chrome、Edge 的浏览器扩展。它提供书签检索、分类建议、批量操作和历史备份；需要时，也可以连接你自己的模型 API 来辅助整理。整理建议先预览、再确认，不会在分析阶段直接移动书签。

**当前版本：3.7.0** · Manifest V3 · Chrome 120+ / 对应 Chromium 内核浏览器

[**下载最新安装包（GitHub Releases）**](../../releases/latest) · [查看版本记录](CHANGELOG.md) · [提交问题](../../issues)

> 下载 Release 附件中的 `markmind-3.7.0.zip`，解压后即可通过浏览器开发者模式安装；不需要 Node.js 或编译。

## 功能

| 功能 | 说明 |
| --- | --- |
| 智能分类 | 根据标题、网址和原目录生成分类建议；优先主文件夹，必要时才拆分子目录 |
| AI 助手 | 用自然语言描述任务，筛选指定范围内的书签，生成移动或重命名方案 |
| 书签库 | 搜索、查看、修改书签或文件夹名称，直接编辑链接、确认删除 |
| 印象搜索 | 忘记名称也能按用途搜索；本地匹配可离线使用，AI 扩展为按需功能 |
| 死链检查 | 检查 HTTP(S) 网址的可访问性；404/410 作为疑似失效，其他异常单独标注 |
| 备份与恢复 | 浏览历史备份、创建书签副本、从备份恢复，批量操作支持撤销记录 |

## 安装

目前提供**开发者模式安装**，无需构建或安装依赖。

1. 从 [Releases](../../releases/latest) 下载 `markmind-3.7.0.zip` 并解压。也可以使用源码目录安装。
2. 打开 `chrome://extensions/`（Edge 使用 `edge://extensions/`）。
3. 启用右上角的「开发者模式」。
4. 点击「加载已解压的扩展程序」，选择包含 `manifest.json` 的项目根目录。
5. 点击 MarkMind 图标开始使用。需要模型功能时，在设置中配置 API 服务商与密钥。

如果以前安装过不同扩展 ID 的 MarkMind，旧版密钥不会自动迁移。建议先停用旧扩展，避免多个版本同时操作书签。

## 基本使用

**整理书签**：打开「概览」开始分析 → 进入「分类」检查建议 → 调整需核实项目 → 备份并应用。任何尚未应用的方案都可以放弃。

**按指令整理**：在「AI 助手」选择一个或多个文件夹、书签，输入如“在学习下面创建打字文件夹，将相关网站放进去”，确认建议后执行。任务只允许修改已选范围内的书签。

**优化名称**：切换至 AI 助手的命名模式，选择范围，生成新旧标题对照，审核后应用。命名操作不会修改网址或目录。

**印象搜索**：在书签库输入“PDF 转换”“练习打字”等用途描述。本地搜索不消耗模型额度；点击 AI 扩展搜索会将部分书签信息发往已配置的服务商。

**检查死链**：在书签库切换至「死链检测」，授权访问网站后进行检测。结果可以逐条打开、编辑或确认删除，不会自动清理。

**恢复书签**：在「备份」页选择历史备份，核对数量和日期后执行恢复。恢复过程会尽量保留当前书签的归档副本；重要书签仍建议另外导出 Chrome HTML 备份。

## AI 服务商

默认使用 DeepSeek，也支持 OpenAI、OpenRouter、阿里云百炼及硅基流动。各服务商的 API Key 和模型配置独立保存于 `chrome.storage.local`，请求使用固定 HTTPS 接口，不支持任意自定义 API 域名。

模型调用与网站可访问性检测需要联网，并可能产生第三方 API 费用。AI 分类依据书签标题、网址和路径，不会自动读取网站正文，因此专业性很强的书签仍应检查结果。详细信息见 [隐私说明](docs/PRIVACY.md)。

## 开发与测试

运行环境：Node.js 20 或更高版本。扩展本身是原生 JavaScript，不依赖前端框架或运行时构建链。

```bash
npm run check    # 验证 manifest、脚本和测试
npm test         # 运行单元与后台任务测试
npm run package  # 生成 dist/markmind-3.7.0.zip（需要系统 zip 命令）
```

测试包含目录规划、限定操作范围、AI 任务取消、历史备份操作、印象搜索规则、死链状态判断以及 API 接入层。单元与模拟测试不等同于真实 Chrome 扩展安装和第三方 API 的端到端验证。

代码结构说明见 [开发文档](docs/DEVELOPMENT.md)，重要改动记录见 [更新记录](CHANGELOG.md)，发布流程见 [版本发布说明](docs/RELEASING.md)。

## 安全与使用边界

- 大规模移动、重命名或恢复前，先确认完整备份存在；必要时额外导出浏览器书签 HTML。
- API Key 仅存储在浏览器本地扩展存储中，但**并非加密保险箱**。共享电脑请谨慎使用。
- HTTP 404/410 仍可能受网站权限、反爬策略、跳转状态影响；检查结果仅作参考。
- Chrome 的后台 service worker 可能被浏览器挂起。进度会分批保存，但断网、关机与扩展停用可能导致任务中断。
- 未选定开源许可证。未经权利人明确许可，请勿将本仓库内容作为已获开源授权的代码复用或分发。

问题反馈与安全漏洞提交流程见 [CONTRIBUTING.md](CONTRIBUTING.md) 和 [SECURITY.md](SECURITY.md)。
