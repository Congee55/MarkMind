# 隐私与数据说明

MarkMind 直接在浏览器扩展环境中运行，没有单独的 MarkMind 账号系统或自建云端服务器。

## 数据保存在什么地方

- **书签**：通过浏览器 `bookmarks` API 读取；移动、改名或删除仅在用户确认操作后执行。
- **插件设置**：包括所选服务商、模型名和 API Key，保存在 `chrome.storage.local`。浏览器不会将这些密钥当作加密密码库管理。
- **分析结果及进度**：保存在本地扩展存储中，用于在关闭弹窗后恢复查看。缓存中可能包括书签的标题、网址、路径和模型建议。
- **备份**：由扩展在浏览器书签树内创建 `MarkMind Backup` 文件夹；恢复期间可能创建 `MarkMind Archive` 归档。

## 哪些情况下会产生外部请求

1. 用户主动运行 AI 分类、智能整理、优化命名或 AI 扩展印象搜索时，扩展会向**当前选择的模型服务商**发送执行任务所需的部分书签元数据，包括标题、网址、域名与目录路径。
2. 用户主动运行死链检测并授权站点访问后，扩展会向书签中对应的 HTTP(S) 网站发送 `HEAD` / `GET` 请求，判断访问状态；不会抓取或存储网页正文。
3. 本地印象搜索不调用远程 AI 服务。

第三方模型与网站如何处理请求数据，取决于各自的服务条款及隐私政策。请不要将包含敏感内部网址的书签提交到未经评估的模型服务商。

## 浏览器权限

| 权限 | 用途 |
| --- | --- |
| `bookmarks` | 读取、管理与备份用户确认处理的书签 |
| `storage` | 保存设置、方案、进度、撤销记录及搜索线索 |
| `tabs` | 打开已收藏的网站进行核实 |
| `alarms` | 在弹窗关闭后恢复分批进行的后台任务 |
| 预设 AI API 域名 | 连接用户选定的 AI 服务商 |
| 可选 HTTP(S) 网站访问权限 | 用户启动死链检测时申请，以发起访问状态检查 |

## 删除本地数据

可在 Chrome 的扩展管理页面移除 MarkMind，清除与该扩展 ID 关联的本地设置与缓存。**书签树中已创建的历史备份和归档文件夹不会随扩展卸载自动删除**；如需删除请先确认不再需要恢复。

## 保护措施及限制

- 网络 API 地址使用预先限定的 HTTPS 接口，不支持通过设置输入任意目的域名。
- AI 对书签的建议经过 ID 范围校验；来源范围之外的建议不会直接执行。
- 备份与撤销不能替代浏览器书签 HTML 的离线导出。
- 本项目不提供端到端加密、云端同步或服务端隐私保证。
